I. HƯỚNG DẪN KHỞI CHẠY CHƯƠNG TRÌNH (HỖ TRỢ SONG SONG 2 CÁCH)
--------------------------------------------------------------------------------
Hệ thống hỗ trợ 2 phương thức khởi chạy song song, dùng chung 1 bộ mã nguồn và cấu hình duy nhất:

CÁCH 1: KHỞI CHẠY BẰNG RUN_SERVER.BAT (GIỮ NGUYÊN HOÀN TOÀN)
1. Thầy/Cô và người dùng chỉ cần nhấp đúp chuột vào file ở thư mục gốc:
   -->  run_server.bat

2. File chạy sẽ tự động thực hiện tất cả các bước:
   • Tự động nhận diện thư mục dự án trên mọi ổ đĩa (D:\, C:\, E:\,...).
   • Giải phóng cổng 8080 và 8005 nếu có tiến trình chạy ngầm để tránh xung đột cổng.
   • Đồng bộ và giải nén bản build mới nhất của ứng dụng vào Apache Tomcat 11.
   • Xóa sạch cache uncompress và work cache cũ để nạp mới toàn bộ view và controller.
   • Nạp thư viện xác thực native DLL kết nối CSDL SQL Server (mssql-jdbc_auth-12.8.1.x64.dll).
   • Khởi động máy chủ web Apache Tomcat 11.
   • Tự động mở trình duyệt web hiển thị trang chủ mua hàng tại:
     http://localhost:8080/ShoppingServiceMVC/home
3. Để dừng máy chủ: Nhấn tổ hợp phím Ctrl + C tại cửa sổ CMD đang chạy máy chủ.

--------------------------------------------------------------------------------
CÁCH 2: KHỞI CHẠY TRỰC TIẾP TRONG VISUAL STUDIO CODE (VS CODE - MÀU XANH DƯƠNG)
1. Mở thư mục dự án bằng VS Code:
   -->  File -> Open Folder -> Chọn thư mục "BTVN_9-11"
2. Toàn bộ mã nguồn Java chuẩn MVC được quản lý trực tiếp trong Explorer:
   • Main/Application: vn.iotstar.Application, vn.iotstar.server.TomcatServerRunner
   • Controllers: Admin, Auth, Common, Web
   • DAOs / Repositories: CategoryDao, ProductDao, UserDao và DaoImpl
   • Models / Entities: User, Category, Product, Cart, CartItem, LoginResult
   • Services: CategoryService, ProductService, UserService và ServiceImpl
   • Config / Connection: DBConnection (kết nối SQL Server qua Windows Auth & sa)
   • Utils / Helpers: BCrypt, AdminSecurityFilter, CharacterEncodingFilter, Constant
   • Views / WebApp: JSP, CSS/upload, WEB-INF/web.xml
3. Cách chạy trong VS Code:
   • Cách A: Nhấn F5 (hoặc chọn tab Run & Debug -> Run "ShoppingServiceMVC (F5 - Run Application)").
   • Cách B: Mở file src/main/java/vn/iotstar/Application.java và nhấn nút "Run" CodeLens ngay trên hàm main.
   • Cách C: Nhấn tổ hợp phím Ctrl + Shift + B để chạy Build Task (Maven Clean Package).
4. Khi chạy từ VS Code, lớp Application.java sẽ tự động:
   • Kiểm tra kết nối CSDL SQL Server và in xác nhận trạng thái bảng Users.
   • Giải phóng cổng 8080 và 8005 nếu có tiến trình chạy ngầm (tránh xung đột cổng).
   • Đồng bộ bản build WAR, nạp thư viện DLL Windows Auth và JDBC JARs.
   • Khởi động máy chủ Apache Tomcat 11 và stream log trực tiếp ra VS Code Debug Console.
   • Tự động mở trình duyệt web hiển thị trang chủ: http://localhost:8080/ShoppingServiceMVC/home.
5. Để dừng máy chủ: Nhấn Shift + F5 hoặc nút Stop (■) trên thanh công cụ Debug của VS Code.

IV. ĐIỂM NHẤN BẢO MẬT CHỨC NĂNG LOGIN & REGISTER (THEO TIÊU CHUẨN ĐÁNH GIÁ)
--------------------------------------------------------------------------------
1. Quy trình Đăng Ký Chuyên Nghiệp (REGISTER):
   • Kiểm tra chặt chẽ đầu vào: Không bỏ trống, regex Email, regex Số điện thoại, regex Tên đăng nhập.
   • Kiểm tra chính sách mật khẩu: Độ dài tối thiểu từ 6 ký tự trở lên.
   • Mật khẩu xác nhận bắt buộc trùng khớp với mật khẩu đã nhập.
   • Kiểm tra duy nhất (Unique check) cho cả Email, Username và Phone trong SQL Server.
   • Mật khẩu được băm (hash) 100% bằng thuật toán BCrypt kèm Salt ngẫu nhiên trước khi lưu DB.
   • BẢO MẬT PHÂN QUYỀN: Bắt buộc gán vai trò mặc định là USER (Role 5), không cho phép đăng ký quyền ADMIN.

2. Quy trình Đăng Nhập Linh Hoạt & An Toàn (LOGIN):
   • Đăng nhập được bằng cả TÊN ĐĂNG NHẬP hoặc ĐỊA CHỈ EMAIL.
   • Xác thực mật khẩu thông qua BCrypt.checkpw (chống Rainbow table).
   • Chống Brute-force: Tự động đếm số lần sai; nếu sai >= 5 lần, tạm khóa tài khoản 15 phút.
   • Chống User Enumeration: Trả về thông báo lỗi chung, không để lộ thông tin tài khoản có tồn tại hay không.
   • Chống Session Fixation: Hủy session cũ và cấp session mới khi đăng nhập thành công.
   • Ghi nhớ đăng nhập: Cookie "remember" được gắn cờ HttpOnly=true chống mã độc JavaScript đánh cắp phiên.

3. Phân Quyền Tầng Máy Chủ (Server-Side RBAC Filter):
   • Bộ lọc `AdminSecurityFilter` bảo vệ toàn bộ URL `/admin/*`.
   • Nếu tài khoản USER (Role 5 - khachhang) cố tình truy cập `/admin/*`, máy chủ trả về mã lỗi 403 Forbidden
     và hiển thị trang "Truy Cập Bị Từ Chối", tuyệt đối không cho phép truy cập trái phép.
   • Tài khoản ADMIN (admin, trungnh) được điều hướng vào bảng điều khiển quản trị `/admin/home`.

4. Quên Mật Khẩu & Đổi Mật Khẩu (Forgot / Change Password):
   • Quên mật khẩu (/forgot-password): Sinh mã xác thực Token 6 chữ số có hạn 15 phút.
   • Đổi mật khẩu (/change-password): Bắt buộc kiểm tra mật khẩu cũ trước khi cập nhật mật khẩu mới băm BCrypt.
